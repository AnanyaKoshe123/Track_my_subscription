# UI/UX and Screen Specification: Track My Subscription

## 1. Navigation and Screen Hierarchy
- **Primary Layout**: Persistent Sidebar navigation on desktop, collapsible hamburger menu on mobile devices.
- **Top Navigation Bar**: Currency selector dropdown, global search bar, Add Subscription CTA, AI Assistant toggle, Notification bell icon, and User avatar menu.

## 2. Design System & Styling
- **Framework**: Tailwind CSS.
- **Color Palette**:
  - Primary Brand / Accent: `#7657E8` (Indigo/Purple)
  - Secondary Accent: `#12B886` (Emerald)
  - Dark Theme / Welcome Hero: `#172B3A` / `#004547`
  - Neutral Background: `#F6F7F9`
  - Card Background: `#FFFFFF`
- **Typography**: Clean sans-serif font stack with clear heading hierarchy (`text-3xl font-extrabold`, `text-2xl font-bold`, `text-xs font-semibold`).

## 3. Responsive Behavior
- **Desktop (lg+)**: Side navigation bar pinned to the left, 3-column subscription grid layout, expansive data tables.
- **Tablet / Mobile**: Sidebar tucked into drawer menu toggle, single or dual-column grid layout, horizontally scrollable filter bars.
